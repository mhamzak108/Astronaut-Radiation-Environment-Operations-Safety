# Astronaut-Radiation-Environment-Operations-Safety
AREOS is a Mars EVA safety companion. The astronaut sets a time limit, then AREOS monitors radiation, temperature, dust, slope and suit power using NASA Curiosity and MRO reference data. It rates conditions GO, CAUTION or TURN BACK, warns 20 minutes early and suggests safer routes. Sensor values are simulated. Built with HTML, CSS and JS.
